# dsh-plugin-desktop-notice

> **让 DSH 的每一次"需要你"都及时抵达桌面。** 任务完成、卡住等确认、出错失败——右下角弹窗 + 音效一秒知晓，不用再盯着聊天窗口等待输出。

你的 AI 在埋头干活，你在干嘛？回微信、看文档、开会、摸鱼。然后呢？要么反复切回来看进度，要么回来才发现——**AI 十九分钟前就停下来等权限确认，干等你到现在**。

本插件把 DSH 的关键事件推送到操作系统桌面（Windows 通知中心 / macOS 通知中心），你是被提醒的人，不是盯屏幕的人。

---

## 它解决什么痛点

### ⏸ 痛点一：AI 卡住等你，你不知道（最贵）
权限确认、agent 提问——AI 停下来了，屏幕那头静悄悄。你回来才发现时间在静默燃烧。

**解法**：等待输入即时弹窗（"⏸ AI 在等你 · 需要确认 bash 命令"），默认 5 分钟没人理就再次强提醒；你一回复，提醒自动复位。

### ✅ 痛点二：任务完成时机不可知
跑个长任务就被人质化了——切走不放心，盯着又浪费。

**解法**：完成即弹窗，带**耗时、token 数和结果摘要**——不回终端也能判断要不要立刻回来。

### 🔴 痛点三：任务失败了，很久才发现
**解法**：失败红标弹窗 + 独立音效。瞬时重试中的小错误**不会**打扰你——只在真正终态失败时提醒。

### 🌊 痛点四：通知插件死于骚扰
弹多了被关掉，插件就死了。

**解法**：短时间多条事件**合并为一条**；通知链路任何故障（权限被拒、无桌面环境）自动**静默降级**，绝不弹窗轰炸、绝不影响 agent 主流程。

---

## 功能一览（M1）

- **三类事件通知**：任务完成 / 等待输入 / 任务失败，各自独立开关
- **Windows 原生 Toast**：右下角弹出、自动进通知中心，不依赖 DSH 窗口可见
- **音效系统**：成功 / 等待 / 失败三套内置音效，可换自定义 wav，音量可调
- **防轰炸**：同类事件 10 秒窗口内自动合并（可调）
- **渐进式强提醒**：等待输入 5 分钟未处理自动重发（可调 / 可关）
- **通知摘要**：项目名 / 耗时 / token / AI 结论截断，标题 ≤40、正文 ≤120 字符防系统截断
- **一键测试**：`/desktop-notice/test` 路由发样例通知，配置生效一目了然
- **零打扰兜底**：headless / WSL 无桌面自动禁用；权限不足日志警告 + 降级，不崩溃

## 后续路线

### M2 · 防打扰智能化（已实现，待真机验收）

- **前台检测**：DSH 窗口正在前台时自动不弹——你在盯着看，弹窗是纯噪音；
- **全屏静默**：看视频 / 投屏演示中触发的事件转入队列，退出后合并汇总一条（"刚才 3 个任务完成"）；
- **勿扰时段**：按时间表静默（支持跨午夜）；**等待输入类事件默认豁免**——阻塞在烧你的时间，勿扰也要提醒（可关）；
- **内容增强**：通知带项目名 / git 分支 / 耗时 / token / 结果摘要，一眼判断要不要立刻回来；
- **通知历史落盘**：每次弹窗与被抑制的通知（含原因）都有迹可循；
- **macOS 适配**：`osascript` 零依赖路线，macOS 系统专注模式天然兜底。

### M3 · 多端与数据（已实现，待真机验收）

- **手机推送**：Bark / ntfy / 自定义 webhook，按事件分级路由——完成只发桌面，**等待输入和失败推到手机**（人不在电脑前也收得到）；
- **关键词监听**：输出命中 error / 完成 等信号词即提醒（默认关，每任务最多一条防轰炸）；
- **历史 + 统计浮卡**：右下角面板回看通知历史，招牌统计——**"今天 AI 等了你 X 分钟"**，把阻塞成本量化给你看；
- **Linux 适配**：`notify-send` 路线，尽力而为；
- **发散储备**：TTS 语音播报（摸鱼不用看屏幕）、agent 主动通知工具（让 AI 自己说"跑完这批叫我"）。

## 已知问题（2026-09-06 备忘）

- **横幅（banner）不显示**：通知 100% 到达平台（通知中心可查、WAL 有写入、`ToastNotifier.Setting = Enabled`），但横幅不渲染——已排除：全局开关（已开）、专注助手（已关）、应用身份（已自注册 + 显式横幅标志）、组策略（无）、僵尸平台服务（已强杀恢复）。**待办**：① Win+Shift+S 对照实验（看系统自身横幅弹不弹，区分系统层 vs 身份层）；② 若系统层异常 → `sfc /scannow` 组件修复。功能本身不受影响（通知中心 + 声音 + 浮卡全可用）。
- **M2 焦点探测脚本偶发崩溃**：`win32-focus.ps1`（P/Invoke）在部分场景段错误，已加熔断（连续 3 次失败停 5 分钟），失败时抑制功能自动失效（宁多弹不漏弹），待后续排查。



## 安装与使用

```bash
# 安装到目标 profile（web profile 需重启后生效）
dsh plugin --profile web add <本仓库路径>
```

装好即用（默认配置已是不打扰取向）。想调整：

```yaml
# settings.yaml（插件设置页同效，热更新无需重启）
dsh-plugin-desktop-notice:
  events:
    done:    { desktop: true, sound: "success" }
    waiting: { desktop: true, sound: "notice" }
    error:   { desktop: true, sound: "alert" }
  volume: 60
  mergeWindowSeconds: 10
  escalateWaitingMinutes: 5
```

验证配置（装好并重启 DSH 后，三种方式任选，无需 curl）：

```text
① 浏览器直接打开   http://127.0.0.1:3080/desktop-notice/test?kind=waiting
② npm 脚本         npm run notify:test -- waiting     （省略 kind 则轮流发三态）
③ PowerShell       irm "http://127.0.0.1:3080/desktop-notice/test?kind=error"
```

应立即看到一条测试弹窗 + 听到提示音；若没看到横幅，按 Win+N 查通知中心（横幅可能被系统通知设置/专注助手拦截）。web 端口不是 3080 时，① ② 改端口即可。

## 平台权限说明

| 平台 | 要求 | 行为 |
|---|---|---|
| Windows 10/11 | 系统设置 → 通知 → 允许应用通知 | 权限被拒时插件自动降级（仅音效），日志警告，不会崩溃 |
| macOS（M2） | 首次通知会弹系统授权，允许一次即可 | 拒绝后静默失效，日志可查 |
| 无桌面环境（服务器 / WSL） | 无 | 自动禁用弹窗与音效，仅保留日志 |

**Windows 看不到横幅？按序排查**（真实环境踩坑记录，每一层都会静默吞掉横幅）：

1. **全局总开关**：设置 → 系统 → 通知 →「获取来自应用和其他发送者的通知」；
2. **专注助手**：快捷操作面板里的「专注助手 / 仅优先通知 / 仅限闹钟」开着时，横幅全部静默进通知中心；
3. **应用条目**：通知设置列表里找到「DSH Desktop Notice」（首次通知后自动出现），确认开关打开且包含"横幅"；
4. 以上都正常仍不弹：重启一次电脑（通知平台的展示层在登录时初始化，配置历史的残留可能要重启才清掉）。

> 插件首次运行会在开始菜单注册自己的应用身份（`DSH Desktop Notice.lnk`），这是 Windows 弹横幅的必要条件——比借用其他应用身份更干净，且可以在设置里单独控制。

## 设计原则

- **绝不妨碍主流程**：通知链路任何异常静默降级 + 日志，agent 该跑跑它的；
- **不打扰是默认值**：合并节流默认开启，宁可少弹不误弹；
- **零常驻、零依赖**：纯 ESM 无构建链，事件驱动按需调用系统自带能力（PowerShell WinRT），无第三方二进制。
